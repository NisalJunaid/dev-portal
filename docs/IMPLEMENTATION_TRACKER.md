## 1. Project Goal

Build a Laravel 10 + PostgreSQL client ticketing and project workflow portal with an Asana-inspired UI/UX. The system will allow clients to submit and follow tickets while the Kiel team manages backend workflows for bug tracking, feature sprints, time tracking, comments, timeline/activity history, reporting, and exports.

## 2. Core Requirements

- Laravel 10 application foundation.
- PostgreSQL database backend.
- Asana-inspired UI/UX for project and task management.
- Client ticket submission workflow.
- Kiel backend management workflow.
- Bug tracking workflow.
- Feature sprint workflow.
- Client-specific sprint isolation.
- Kanban view for workflow stages.
- List view for tickets, tasks, and sprint items.
- Timeline view for planning and activity visibility.
- Drag-and-drop interactions for status and ordering changes.
- Time tracking for tickets, bugs, and feature work.
- Blocked/unblocked workflow state management.
- Comments on tickets and work items.
- Ticket timeline/activity history.
- Reports and export functionality.
- Role-based access control.
